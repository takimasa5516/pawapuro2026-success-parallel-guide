# ⚾ パワプロ2026 サクセス『パラレルオールスターズ』特化 攻略ガイド

パワプロ2026-2027の新シナリオ「パラレルオールスターズ」に完全特化した、スマートフォン対応の高機能Web攻略ナビゲーションツールです。

---

## 🌟 主な機能・収録データ

### 1. シナリオ進行フローチャート（全17工程）
- **投手・捕手・野手** の3ポジション別の最適巡回ルートをタブ切り替え表示。
- 行先、目安ターン、TODO、次に必要なポイント、使用コア、時空Lv、同行ペアと選択肢、備考を完全網羅。
- サクセスプレイ中の進行度を管理できるインタラクティブなチェックボックス機能。
- 重要分岐（四条彼女化、聖ジャスミン基礎コツ、25T★250分岐、時空Lv10到達等）のハイライト表示。

### 2. 彼女攻略情報（4名完全対応）
- **四条澄香**（あかつき大附属）、**日和ミヨ**（神楽坂高校）、**虹谷彩理**（天空中央高校）、**本若春陽**（アオハル学園）
- 知合い方・出現時空・同行条件、ラブパワーの恩恵（やる気最大化、練習効果大幅UP、消費体力軽減、差し入れ等）。
- **デート4回目（イベント04）の金特選択肢対比カード**:
  - 選択肢［上］vs［下］で獲得できる金特（Lv2コツ）と詳細効果を、投手／野手別で直感的に対比。

### 3. コンボイベント一覧（全11組）
- 猪狩守×橘みずき、友沢亮×早川あおい、黒珠真×松倉宗光 など全11組を収録。
- 投手・野手別の選択肢ごとの獲得特能Lv3コツ、全ステータス+48経験点。
- **「★基礎能力Lv3コツ持ちのみ」フィルター**: 球速・コントロール・スタミナ・ミート・パワー・守備力のコツがLv3でもらえる重要コンボを一発抽出。
- キャラ名・学校名・獲得コツ名でのリアルタイム絞り込み検索。

### 4. 攻略の鉄則・育成Tips
- **25ターン目 ★250分岐（憧堂景から金特獲得）**
- **時空移動時の体力+25回復の活用術**
- **聖ジャスミン学園＆織田軍の早期到達（基礎能力コツ早期回収）**
- **時空Lv5で継承選手の最速加入（12〜15T目安）**
- **時空Lv10到達で真の最終ボス「テシータ」戦突入**

## 🚀 ローカルでの起動方法

```bash
# 依存パッケージのインストール
npm install

# 開発サーバー起動
npm run dev

# プロダクションビルド
npm run build

# ビルド済み静的プレビュー
npm run preview
```
